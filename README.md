# Notees Brand

**MARGIN — The page is the canvas. The margin is where thought accumulates.**

This repository is the single source of truth for the Notees identity. Every
client (web, CLI, GTK, Flutter) consumes it as a **git submodule at `brand/`**
and nothing else: do not redraw the mark, do not re-derive the colours, do not
re-pick the typefaces. Update the identity here, tag it, and bump the pinned
submodule ref in each client.

## What lives here

- `guidelines/` — the full guidelines kit (13 pages, `notees-guidelines.pdf`,
  `fonts.md` with sources and licences). Start at the PDF.
- `assets/logo/` — master SVGs (symbol, wordmark, horizontal/stacked lockups,
  one-colour light/dark, full-colour light/dark), favicon 16/32/48, app icon 512.
- `assets/tokens/` — machine-readable design tokens: `tokens.css`,
  `tokens.scss`, `tokens.dtcg.json` (DTCG format), `tailwind.palette.js`,
  `palette.gpl` (GIMP/Inkscape), `fonts.css`, `swatches.html`.
- `identity.json`, `palette.json` — the machine-readable identity and palette
  (roles, scales, adjustments) as generated by the identity pipeline.

## The system in one paragraph

One permanent vertical rule in iron ink is the coordinate; small **Advance
Green** (`#2e5e46`) annotations appear where thought lands. The margin is
permanent; the green mark is the act of adding. **Newsreader** carries the
words you read; **Instrument Sans** carries the interface you operate;
**JetBrains Mono** carries data. The ground is warm paper (`#f7f4ec`); the
dark ground is warm near-black (`#161412`).

| Role | Value | Use |
|---|---|---|
| Advance Green | `#2e5e46` | annotations, links, active states, the arriving mark |
| Iron Ink | `#1c1a16` | the margin, wordmark, text |
| Paper | `#f7f4ec` | light ground |
| Night | `#161412` | dark ground |

Full roles, scales and modes are in `palette.json` / `assets/tokens/` — the
table above is a summary, the tokens are authoritative.

## Typefaces (OFL, via Google Fonts)

- **Instrument Sans** — display/chrome (600 headings, 500–700 available).
- **Newsreader** — reading text at `opsz` 14–18, weights 400–500.
- **JetBrains Mono** — data, code, timestamps.

Do not subset or convert the font files for redistribution; link or bundle per
each OFL licence (see `guidelines/fonts.md`).

## Consuming as a submodule

```sh
git submodule add git@github.com:miquelrosell99/notees-brand.git brand
git -C brand fetch --tags
git submodule set-branch -b main brand   # or pin: git -C brand checkout v1.0.0
```

- Never commit inside `brand/`; bump the ref instead.
- Logo clear space = the cap height of the wordmark; minimum size 16 px.
- Misuses: annotations never off the page; the rule never laid horizontal;
  no stretching, recolouring, or rearranging (see guidelines page 5).
